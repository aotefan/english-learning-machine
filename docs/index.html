搭建之前，你可能想知道

英语学练机是什么？

它是一套开源英语口语练习原型，包含 ESP32-S3 固件、Python 服务和网页管理界面。可把中文或中英混说转成英语，提供示范、陪练与复习。

是否完全离线、完全免费？

当前推荐路径调用豆包 / 火山引擎云端服务，不能离线推理。代码开源，硬件、服务器和 API 可能收费。

支持全双工和打断吗？

日常推荐半双工。全双工 / AEC 候选尚未通过可靠的长期实机验收，不作为稳定能力承诺。

语音和学习内容存在哪里？

云端模式发送语音与文本给对应供应商。原始音频默认不落盘，诊断录音例外；学习文字和事件默认保留七天，日志、备份和供应商留存需单独管理。

是否证明可以提高孩子的英语水平？

没有学习成效研究或能力评分结论。家庭可在成年人参与配置与管理的情况下尝试；自评和跟读次数不等于语言能力提升。
