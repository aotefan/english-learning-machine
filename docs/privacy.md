# 隐私与数据去向

代码可自托管，但推荐的云端推理路径会向供应商发送语音与文本。部署前应让实际使用者了解数据去向；涉及家庭成员或儿童时，应由负责配置的人管理授权、账户和保留策略。

| 数据 | 去向与默认行为 |
| --- | --- |
| 麦克风音频 | 经服务器发送语音供应商；默认不保存原始录音 |
| 诊断音频 | 仅显式开启捕获时保存到状态目录，数量和时长受限；需自行删除 |
| 转写与英语表达 | 语言模型处理；SQLite 学习文字和事件默认保留最近 7 天 |
| 用量、费用、设备控制 | 存在私有状态库；账单元数据可保留更久 |
| 运行日志和备份 | 不应公开；数据库七天清理不等于所有日志与备份自动同步删除 |
| API Key | 只在自己的服务端私密配置中 |
| 设备令牌 | 每设备单独生成；服务端只存其 SHA-256 摘要 |

供应商数据保留、地域和账户设置由供应商及部署者管理，本项目不能替代这些设置。公开仓库中的句子是说明和测试素材，不包含生产日志或家庭录音。不要把真实对话、截图、设备标识或密钥放入公开 Issue。
