Before you build

What is English Learning Machine?

An open-source English speaking-practice prototype with ESP32-S3 firmware, a Python server and a browser dashboard. It supports Chinese-to-English expression, spoken examples, conversation practice and review.

Is it offline or free to run?

The recommended path calls Doubao / Volcengine cloud APIs and is not offline. Source is open, while hardware, hosting and API usage may cost money.

Does it support reliable full-duplex conversation?

The recommended configuration is half-duplex. Full-duplex and AEC candidates remain experimental and have not passed reliable long-duration hardware validation.

Where does speech data go?

Cloud mode sends audio and text to the corresponding providers. Raw audio is not saved by default, except opt-in diagnostics. Learning text and events expire after seven days; logs, backups and provider retention need separate management.

Is improved proficiency demonstrated?

No educational-outcome study or proficiency assessment is provided. Repetition counts and self-assessments are usage records, not proof of learning gains.
